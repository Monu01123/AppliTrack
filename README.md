# AI Job Application Tracker

A full-stack web app to track job applications, score resumes with AI, and automate follow-up reminders.

## Stack
- **Frontend**: React.js, React Router v6, Recharts, @hello-pangea/dnd
- **Backend**: Node.js, Express, Prisma ORM, PostgreSQL (Neon)
- **Auth**: JWT (access + refresh), bcrypt
- **AI**: Google Gemini API
- **Email**: Nodemailer + Gmail SMTP
- **DevOps**: Docker, GitHub Actions, Render + Vercel
